# 🚀 API REST con FastAPI + Groq AI (Dockerizada)

Este proyecto expone un **API REST en Python usando FastAPI** que consume el **API de IA de Groq** mediante **API Key**, recibe un mensaje del cliente y devuelve un análisis generado por IA.

El servicio está **dockerizado**, expuesto en el **puerto 8000** y permite **acceso desde cualquier origen (CORS habilitado)**.

---

## 📌 Características

- ✅ FastAPI + Python 3
- ✅ Integración con Groq AI
- ✅ Entrada JSON estructurada
- ✅ Docker ready
- ✅ Puerto 8000
- ✅ CORS habilitado (`*`)
- ✅ Swagger UI incluido
- ✅ Ideal para n8n, frontends y laboratorios educativos
